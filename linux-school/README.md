# self-upgrade

Личный курс по устройству Linux на основе ALT. Статический сайт без сборки: открывается на GitHub Pages и ставится на экран «Домой» на iPhone.

## Состав
- `index.html`, `app/` — движок (задания, повторение по коробкам, прогресс, учебный терминал, поиск, шпаргалки).
- `courses/linux/` — курс: `course.json` (слои и источники) и по файлу на слой (`L1.json` …). Новый курс — новая папка рядом.
- `tools/check.py` — проверка файлов курса: `python3 tools/check.py`.
- `sw.js`, `manifest.webmanifest`, `icons/` — работа без сети и значок.

## Запуск локально
`python3 -m http.server 8000` в этой папке, затем http://localhost:8000/

## Публикация на GitHub Pages
Settings → Pages → Source: ветка `main`, папка `/ (root)`. Адрес: `https://<имя>.github.io/<репозиторий>/`.
На iPhone: открыть адрес в Safari → «Поделиться» → «На экран Домой».
При выпуске обновления поднимите `VERSION` в `sw.js`.

## Как добавить материал
Тема — объект в файле слоя: `read` (конспект абзацами), `items` (задания), `src` (источники из `course.json`), необязательные `blocks` и `alt`.
Типы заданий: `choice`, `flip`, `assemble`, `output`, `case`, `explain`, `tour`, `lab`.
Чужие тексты целиком не вносим: пересказываем своими словами, ссылку добавляем в `sources`.

## Исходные материалы
PDF-источники (ALT Wiki, Шоттс, ядро, FHS) лежат у вас локально и внесены в `.gitignore`: репозиторий публичный, чужие тексты в нём хранить нельзя. В курсе только пересказ своими словами и ссылки.
